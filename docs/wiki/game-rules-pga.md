# PGA (Men's Golf) Game Rules

Each player owns **3 letters** (A through Z). Majors only — no regular
PGA Tour events. Unlike every other league, the "team" is a letter of the
alphabet: a letter's score at a major sums the scores of **every player in
that major's field whose last name starts with that letter**.

Per-player scoring at a major:

| Result                    | Points |
|--------------------------------|--------|
| Makes the cut                    | +5     |
| Finishes 21st–30th                | +2.5   |
| Finishes 16th–20th                 | +3.5   |
| Finishes 11th–15th                  | +4.5   |
| Finishes 10th                        | +5     |
| Finishes 9th                          | +5.5   |
| Finishes 8th                           | +6     |
| Finishes 7th                            | +7     |
| Finishes 6th                             | +8     |
| Finishes 5th                              | +9     |
| Finishes 4th                               | +10    |
| Finishes 3rd                                | +12.5  |
| Finishes 2nd                                 | +17.5  |
| Wins                                          | +25    |

Unlike the round-by-round leagues, these placement bonuses are **not**
cumulative with each other — a player finishes in exactly one position, so
only one placement bonus applies. The "makes the cut" bonus is separate and
additive on top of whichever placement bonus applies (a player who misses
the cut scores 0 for that major; a player who makes the cut but finishes
outside every listed band, e.g. T35, still banks the flat +5 for making
the cut).

Example: if a letter has three players in a major's field, one misses the
cut (0 pts), one makes the cut and finishes T24 (5 + 2.5 = 7.5 pts), and
one wins the tournament (5 + 25 = 30 pts), that letter's total for the
major is 0 + 7.5 + 30 = 37.5 points.
