# MLB Game Rules

Each player owns **4 MLB teams**. Points below accrue per owned team and sum
to that player's total MLB score for the season.

| Event                  | Points |
|-------------------------|--------|
| Regular-season win       | +2     |
| Regular-season loss      | -1     |
| Win division             | +5     |
| Win Division Series (DS) | +15    |
| Win pennant (LCS)        | +30    |
| Win World Series (WS)    | +30    |
