# URC (United Rugby Championship) Game Rules

Each player owns **2 URC teams**. Points below accrue per owned team and
sum to that player's total URC score for the season.

| Event                                          | Points |
|-------------------------------------------------|--------|
| Per league table point                           | +2     |
| Per 10 points of points difference (PF-PA)         | +1     |
| Qualify for the playoffs (top 8)                     | +10    |
| Win Quarterfinal (reach Semifinal)                      | +15    |
| Win Semifinal (reach Grand Final)                          | +25    |
| Win the Grand Final (champion)                                | +35    |

The base is EPL-style (table points + a differential term) — a club's
league table points already include rugby's own try-bonus and losing-bonus
points, so nothing extra is needed there. Points difference (points for
minus points against) swings much wider across a rugby season than a
soccer goal differential can, so it's scaled down 10x here to land at a
similar contribution size to EPL's GD term instead of dominating the
score. On top of the table, URC has an actual knockout bracket (EPL
doesn't), so cumulative playoff-round bonuses are layered on — 3 rounds
(Quarterfinal, Semifinal, Grand Final), the same scale WNBA uses for its
own 3-round, conference-less bracket.

Bonuses stack cumulatively: the Grand Final winner also banks the
playoff-qualification, Quarterfinal, and Semifinal bonuses.

Roster: 2 teams per player, drawn from the full 16-club league (4 Irish
provinces, 4 Welsh regions, 4 South African sides, 2 Scottish, 2 Italian
— see `CLAUDE.md`).
