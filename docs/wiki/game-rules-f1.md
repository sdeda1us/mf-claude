# F1 (Formula 1) Game Rules

Each player owns **1 F1 constructor** (a works team fielding two cars all
season — think of it as a club, like an EPL team, not an individual
driver). All stats below combine both cars' results across the season.

| Event                                          | Points |
|-------------------------------------------------|--------|
| Points finish (P1-P10, per car per race)          | +1     |
| Non-points finish or DNF (per car per race)        | -1     |
| — additional bonus if a podium (P1-P3)              | +3     |
| — additional bonus if a race win                     | +5     |
| Pole position                                          | +2     |
| Fastest lap                                             | +1     |
| Sprint points finish (top 8, per car per sprint)          | +1     |
| — additional bonus if a sprint podium                      | +1     |
| — additional bonus if a sprint win                           | +2     |
| Constructors' Championship — 1st                               | +30    |
| Constructors' Championship — 2nd                                 | +18    |
| Constructors' Championship — 3rd                                   | +10    |

Bonuses stack cumulatively, same convention as every other league here: a
race win banks the points-finish, podium, *and* win bonus simultaneously
(+1 +3 +5 = +9 for that one result). Sprint results are a completely
separate set of counters from main-race results — a strong sprint weekend
doesn't touch a car's main-race points-finish/podium/win tally, and vice
versa. The Constructors' Championship bonus is a single flat bonus at
season's end, exclusive across places — a team finishing 4th or lower gets
none of it, and a champion doesn't also collect the 2nd/3rd bonuses.

Roster: 1 team per player, drawn from the current 11-constructor grid (see
`CLAUDE.md` for the roster and season dates, including the Cadillac/Audi
notes). With 6 players and an 11-team pool, at least 5 constructors always
go undrafted — comfortable surplus, no risk of the pool running dry.
