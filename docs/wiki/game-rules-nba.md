# NBA Game Rules

Each player owns **4 NBA teams**. Points below accrue per owned team and sum
to that player's total NBA score for the season.

| Event                     | Points |
|-----------------------------|--------|
| Regular-season win           | +3     |
| Regular-season loss          | -1     |
| Qualify for playoffs         | +10    |
| Win Round 1                  | +10    |
| Win Round 2 (Conf. Semis)    | +15    |
| Win Conference Championship  | +25    |
| Win NBA Championship         | +30    |
