# NFL Game Rules

Each player owns **4 NFL teams**. Points below accrue per owned team and sum
to that player's total NFL score for the season.

| Event                                    | Points |
|--------------------------------------------|--------|
| Regular-season win                          | +10    |
| Regular-season tie                          | +5     |
| Win Wild Card round (or 1st-round bye)      | +10    |
| Win Divisional round                        | +20    |
| Win Conference Championship                 | +30    |
| Win Super Bowl                               | +40    |

A team that earns a first-round playoff bye scores the same +10 as a Wild
Card round win, since it skips straight to the Divisional round.
