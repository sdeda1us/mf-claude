# NHL Game Rules

Each player owns **4 NHL teams**. Points below accrue per owned team and sum
to that player's total NHL score for the season.

| Event                        | Points |
|---------------------------------|--------|
| Regulation win                      | +3     |
| Regulation loss                     | -1     |
| Overtime/shootout win               | +2     |
| Overtime/shootout loss              | 0      |
| Qualify for playoffs               | +10    |
| Win Round 1                         | +10    |
| Win Round 2 (Conf. Semis)           | +15    |
| Win Conference Championship         | +25    |
| Win Stanley Cup                     | +40    |

A win is worth less if it needed overtime or a shootout to get there, and an
overtime/shootout loss no longer carries the small consolation bonus it used
to -- regular-season scoring now rewards regulation results specifically,
not just "who won."
