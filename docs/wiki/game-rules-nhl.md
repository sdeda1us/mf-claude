# NHL Game Rules

Each player owns **4 NHL teams**. Points below accrue per owned team and sum
to that player's total NHL score for the season.

| Event                        | Points |
|---------------------------------|--------|
| Win (regulation, overtime, or shootout) | +3     |
| Regulation loss                   | -1     |
| Overtime/shootout loss             | +2     |
| Qualify for playoffs               | +10    |
| Win Round 1                         | +10    |
| Win Round 2 (Conf. Semis)           | +15    |
| Win Conference Championship         | +25    |
| Win Stanley Cup                     | +40    |

All wins score the same regardless of how the game ended. A loss that goes
to overtime/shootout scores +2 instead of the usual -1 for a regulation
loss — a small consolation for pushing the game past regulation.
