# NWSL Game Rules

Each player owns **2 NWSL teams**. Points below accrue per owned team and
sum to that player's total NWSL score for the season.

| Event                                              | Points |
|-------------------------------------------------------|--------|
| Per point in the standings                              | +2     |
| Per goal of goal differential (GD)                        | +1     |
| Win the NWSL Shield (best regular-season record)                | +15    |
| Qualify for the playoffs (top 8)                                  | +10    |
| Win Quarterfinal (reach Semifinal)                                   | +15    |
| Win Semifinal (reach Championship)                                      | +25    |
| Win the NWSL Championship                                                  | +35    |

The regular-season base is identical in style and weight to EPL's (points +
goal differential). NWSL, like WNBA, has used a single unified standings
table with no conference split since well before this app's tracking
window, and its playoffs are a single 8-team bracket (Quarterfinal,
Semifinal, Championship — 3 rounds, not 4), so the round bonuses reuse
WNBA/URC's 3-round scale (10/15/25/35 minus the qualify bonus already
counted) rather than MLS's 4-round one. The NWSL Shield — best overall
regular-season record — gets its own bonus, mirroring MLS's Supporters'
Shield.

Bonuses stack cumulatively: 2025 champion Gotham FC (the No. 8 seed) banks
the playoff-qualification, Quarterfinal, and Semifinal bonuses too, not
just the +35 for the Championship itself.

Roster: 2 teams per player, drawn from the full 16-team league (see
`CLAUDE.md`). Two of those 16 — Boston Legacy FC and Denver Summit FC — are
brand-new 2026 expansion franchises with no prior-season history.
