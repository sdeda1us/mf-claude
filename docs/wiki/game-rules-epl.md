# EPL Game Rules

Each player owns **2 EPL teams**. Unlike the other leagues, EPL scoring is
based on final league-table standing rather than individual
wins/losses/playoff rounds (the Premier League has no playoffs).

| Event                          | Points               |
|-----------------------------------|-----------------------|
| Per point in the league standings | +2                    |
| Per goal of goal differential (GD) | +1 (can be negative) |

A team's standings points come from the usual 3-for-a-win/1-for-a-draw
Premier League table. Goal differential can be negative, so this component
can subtract from a team's score.
